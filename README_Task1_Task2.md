# FSDL Experiment 1 - Task 1 & Task 2

Implemented on the original Luxury Stay Hotel project.

## Task 1 - Layout & Container Setup
- Bootstrap `.container` used for responsive content width and margin alignment.
- Bootstrap `.container-fluid` used for the full-width service/contact strip.
- Responsive Bootstrap breakpoints are used through `container`, `col-*`, and responsive flex classes.

## Task 2 - Responsive Grid Layout
- Bootstrap `.row` used to create grid rows.
- Responsive columns use classes such as:
  - `.col-12`
  - `.col-sm-6`
  - `.col-md-4`
  - `.col-lg`
- On mobile, content stacks vertically.
- On larger screens, content appears side-by-side.

## Files
- `index.html` - main page with Task 1 and Task 2
- `Catalogue.html` - room catalogue with responsive Bootstrap grid
- `Style.css` - custom styling
- `Login.html` - responsive login page
- `Register.html` - responsive registration page

Bootstrap 5.3.3 is loaded through the official jsDelivr CDN.
